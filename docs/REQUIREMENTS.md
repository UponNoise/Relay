## 歧义与冲突处理

- 原文 CLI 是建议命名：保留全部建议命令，增加 project show/update、local show/set 和 event show，满足回读及迁移配置。
- “所有修改”包含文件产物：业务修改必填 request_id；init/import/export 输出保留 request_id 与操作标识；本机配置操作也提供请求防重。
- 非负责人追加事件与旧会话失效兼容：旧领取不能修改负责人字段，仍有效本机会话可追加建议；迁移前会话整体失效。
- “用户确认”采用显式来源和说明，不构建虚假的认证边界。
- 完整包选文件，不默认递归；用户必须显式停工确认，工具检查不替代外部文件锁。
- 同机新目录恢复不等于跨电脑验证；第二 harness 即使安装也不等于本次完成实测。
- 终态不重开；无自定义状态、自动总结、自动同步和运行器。
- 无阻塞业务信息缺口。自动加载、其他平台、真实第二 harness 和跨电脑是验收待测条件，不扩大实现范围。
